# Sprint contract C1: epoch descriptor, chain and lifecycle core

Status: evaluator-reviewed 2026-08-20 (plan-level critique incorporated:
DEC-004..DEC-009). Implementation approved to start.

## Requirement being solved

C-01, C-02, C-03 (lifecycle objects), C-05, C-07 (cross-epoch), C-12, C-13,
foundation for C-04/C-06/C-08..C-17. Spec: `docs/EPOCH_LIFECYCLE.md` (draft).

## Files/components expected to change

- nomad-protocol: `docs/EPOCH_LIFECYCLE.md` (spec), vectors under
  `docs/vectors/` if adopted.
- nomad-testnet: new `live/epoch` package (canonical binary encoding,
  descriptor encode/verify, chain store, state machine incl. rotation-retry
  policy hooks, 3-of-5 profile negative tests); `cmd/nomad-epoch` or
  extension of existing CLIs; tests + vectors. No changes to existing
  `live/topology`, `live/committee`, `live/dkg` domain semantics; existing
  objects embedded by exact bytes (DEC-005).

## Exact threat being mitigated

- Cross-epoch/context transplant of lifecycle artifacts (activation,
  approval signatures).
- Split-brain: two valid conflicting descriptors for one epoch activating
  (silently or at all).
- Rollback to a retired epoch descriptor.
- Membership capture: topology authority (or any single party) changing
  operator membership without a previous-committee quorum.
- Activation timing influenced by private state.

## Expected positive behavior

- A genesis descriptor and a chained N+1 descriptor with full activations and
  a previous-epoch approval quorum verify; the manager reports the correct
  PREPARING/READY/ACTIVE/RETIRED state as a pure function of (chain, clock).
- Public vectors reproduce descriptor digests byte-exactly.

## Expected negative behavior (all fail closed)

- Missing/insufficient/duplicate/revoked approvals rejected.
- Missing or wrong-epoch activation signatures rejected.
- Wrong previous digest, wrong epoch number, wrong network rejected.
- Second distinct descriptor for same epoch: recorded as equivocation, both
  refused, chain halted.
- Descriptor for an epoch <= highest retired epoch rejected.
- Activation signature transplanted from another descriptor/epoch rejected.
- Tampered canonical bytes change the digest and fail verification.

## Tests/evidence needed to call it verified

- Unit tests for every negative case above; race-enabled.
- Golden vectors committed (deterministic keys derived from fixed seeds,
  test-only) and verified in CI.
- A two-epoch integration test in nomad-testnet: genesis DKG -> N active ->
  N+1 ceremony+DKG -> N+1 READY -> activation at boundary -> N retired,
  driven entirely by public schedule inputs on a fake clock.
- Evaluator review of the diff.

## Explicit non-claims

- No WAN, no independent administration, no erasure evidence yet (C-08 in
  sprint C2), no revocation flows yet (C3 sprint), no live Compose gate
  update yet (comes with the manager integration).
